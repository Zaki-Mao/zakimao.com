当预测市场遇上AI新闻分析：我为什么要做BeHolmes？

缘起：信息不对称下的思考

作为一个关注预测市场的普通人,我经常在 Polymarket 上浏览各种事件的赔率变化。每当看到某个市场的概率出现剧烈波动时,我都会有一个疑问:这背后发生了什么?

是特朗普又突然说啥了？还是市场大户的资金有异动了？还是某个地方又开打了？

这种信息不对称让我意识到:对于普通投资者来说,最大的痛点不是缺少交易平台,而是缺少将实时新闻与市场变化关联起来的能力。

于是,我萌生了一个想法:能不能做一个工具,用户输入相关新闻,AI可以进行分析推理,帮助普通人理解市场波动背后的原因，给出交易建议?

我的目标受众

这个工具主要面向两类人群:

1. 普通关注者

  • 对预测市场感兴趣,但不一定参与交易
  • 想了解世界大事的最新动态
  • 希望通过市场反应来判断事件的真实概率

2. 潜在交易者

  • 已经在 Polymarket 或其他预测市场有账户
  • 需要快速获取信息来辅助决策
  • 希望在信息传播的早期阶段就能捕捉到关键信号

对于这些用户来说,他们不需要复杂的量化模型,也不需要专业的金融分析工具。他们需要的是:一个简单直观的界面,能够将新闻、分析和市场数据整合在一起。

技术架构：四个关键组件

为了实现这个愿景,我选择了以下技术栈:

1. Streamlit - 快速构建交互界面

选择 Streamlit 的理由很简单:

  • 纯 Python 开发,无需前端知识
  • 部署便捷,分享链接即可使用
  • 交互组件丰富,适合快速原型开发

对于个人开发者来说,Streamlit 让我能够在几天内就搭建出一个可用的产品。

2. Exa.ai - 新闻搜索引擎

这是整个系统的核心。Exa 不是传统的搜索引擎,而是专门为AI应用设计的语义搜索API。它的优势在于:

  • 能够理解查询意图,而不仅仅是关键词匹配
  • 返回高质量的新闻源,过滤掉垃圾内容
  • API调用简单,返回结构化数据

3. Gemini 2.5 - AI推理分析

Google 的 Gemini 2.5 模型负责对新闻进行深度分析:

  • 提取关键信息点
  • 分析事件对 Polymarket 市场的潜在影响
  • 给出基于新闻的概率预测

相比其他模型,Gemini 在长文本理解和多步推理方面表现出色,特别适合新闻分析这种场景。

4. Polymarket API - 市场数据集成

通过 Polymarket 的 API,我能够:

  • 获取实时市场赔率
  • 追踪价格变化趋势
  • 将新闻分析与市场反应进行对照

工作流程

整个系统的工作流程如下:

  1. 用户输入感兴趣的新闻，甚至谣言
  2. 系统通过 Exa.ai 搜索相关最新新闻，并从polymarket市场中寻找有没有和这个新闻相关的预测问题
  3. Gemini 2.5 分析新闻内容,提取关键信息
  4. 结合 Polymarket 当前赔率, 给出分析报告。如果polymarket中没有与这个新闻相关的预测问题，AI也可以直接分析新闻本身，告诉用户这背后的逻辑，包括新闻背景，多角度分析，事实核查，影响分析，传统金融市场交易建议等。
  5. 用户可以基于这些信息做出更明智的判断。

遇到的困难

挑战1: Exa 搜索的不稳定性

在开发过程中,我遇到的最大问题就是 Exa.ai 搜索结果的不确定性。

症状非常诡异:

  • 同样的查询,第一次能搜到10条结果,第二次却返回空
  • 代码逻辑完全没问题,但搜索突然失效
  • 有时候明明存在相关新闻,Exa 却找不到

起初我以为是 API 配额的问题,但检查后发现不是。后来我意识到,这可能与以下因素有关:

  1. 查询语句的微妙差异:即使是略微不同的表述,Exa 的语义理解也可能产生截然不同的结果
  2. 新闻源的更新延迟:Exa 索引新闻可能需要一定时间
  3. 搜索API的限流策略:可能存在某种隐藏的速率限制

我的解决方案:

  • 实现了查询重试机制,如果第一次搜索失败,会尝试改写查询语句
  • 提供了手动搜索选项,让用户可以自己调整查询词

挑战2: 核心问题 - "为什么不直接用 Grok/Gemini 搜索?"

这是我在分享这个项目时,最常被问到的问题。

首先要澄清:我并不是说要完全放弃 Grok 或其他大模型的搜索功能。

恰恰相反,我的理念是:工具组合使用,多一个视角,多一份判断依据。

推荐的组合使用方式

一个理想的信息收集和决策流程应该是这样的:

第1步: 获取一手消息

  • 使用金十数据等财经快讯平台,第一时间捕捉重大新闻
  • 关注官方账号、权威媒体的推送

第2步: 多角度搜索和分析

  • 用 Grok 搜索,获取X(Twitter)上的实时讨论和多元观点
  • 用 我的工具 (Exa + Gemini),获取主流媒体报道和深度推理分析
  • 两者结合,既有社交媒体的即时反应,又有专业媒体的权威解读

第3步: 综合判断

  • 对比不同来源的信息
  • 参考 Polymarket 市场的实时反应
  • 做出更全面、更理性的决策

为什么需要这个工具作为补充?

虽然 Grok 等大模型内置了搜索功能,但在具体使用场景中,各有侧重:

Grok 的优势:

  • 实时性极强,直接抓取 X 平台的最新动态
  • 能捕捉到社交媒体上的情绪和趋势
  • 搜索范围广,信息来源多样

Grok 的局限:

  • 推理能力相对较弱,在深度分析和逻辑推演方面不如 Gemini
  • 社交媒体信息质量参差不齐,需要人工筛选
  • 难以精准定位权威新闻源

我的工具 (Exa + Gemini) 的优势:

  • Gemini 2.5 的推理能力更强,能进行更深层次的因果分析
  • Exa 专注于高质量新闻源,自动过滤低质量内容
  • 直接与 Polymarket 市场数据关联,输出针对性的预测分析
  • 可以精确控制搜索参数(时间范围、来源类型、结果数量)

我的工具的局限:

  • 主要依赖主流媒体,可能错过社交媒体上的早期信号
  • 相对于 Grok 的实时性稍有延迟
  • 不如 Grok 那样能捕捉公众情绪和舆论走向

实际使用场景举例

假设你在关注某个 Polymarket 市场,比如 "特朗普赦免政策":

场景1: 使用 Grok

  • 输入:"特朗普赦免最新消息"
  • Grok 搜索 X 平台,找到各种实时讨论、爆料、评论
  • 你看到了公众的即时反应,但信息真假难辨,需要自己判断

场景2: 使用我的工具

  • 输入:"特朗普赦免政策"
  • 系统通过 Exa 找到华盛顿邮报、彭博社、路透社等权威报道
  • Gemini 分析新闻,提取关键信息(赦免名单、法律依据、政治影响)
  • 结合 Polymarket 赔率,给出概率预测和影响评估
  • 你得到了一份结构化、有依据的分析报告

最佳实践: 两者结合

  • 先用金十数据看到快讯:"特朗普签署赦免令"
  • 立即打开 Grok,搜索 X 平台上的讨论,了解市场第一反应
  • 同时使用我的工具,获取权威媒体的详细报道和 AI 深度分析
  • 对比 Grok 捕捉的情绪和我的工具提供的理性推理
  • 查看 Polymarket 赔率变化,综合判断是否值得下注

这样做的好处:

  • 速度: 金十数据 + Grok 确保你不错过任何突发消息
  • 深度: 我的工具提供权威来源和深度推理
  • 全面: 既有社交媒体的即时反应,又有专业媒体的分析
  • 多角度: 感性和理性结合,情绪和逻辑并重

不是替代,而是互补

我做这个工具的初衷,从来不是要"替代"Grok 或其他工具。

市场上已经有很多优秀的信息获取渠道:

  • Grok 擅长捕捉社交媒体动态
  • 金十数据 擅长快讯推送
  • 传统搜索引擎 擅长全网检索
  • 专业财经终端 擅长数据分析

我的工具想做的,是在这个生态中找到一个独特的位置:

  • 聚焦于 Polymarket 相关的新闻分析
  • 提供 权威来源 + AI 深度推理 的组合
  • 降低 普通用户的信息筛选成本

就像你不会只用一个消息源做投资决策一样,多一个工具,就多一个视角,多一份保障。

在信息爆炸的时代,真正的优势不是拥有某一个最强的工具,而是知道如何组合使用不同的工具,快速建立信息优势。

未来展望

这个项目还在持续迭代中,我计划增加以下功能:

  • 历史回溯分析:对比过去类似事件的新闻和市场反应
  • 多市场关联:分析一个新闻对多个相关市场的影响
  • 实时推送:当重大新闻出现时,自动通知用户
  • 社区协作:允许用户分享自己的分析和见解

结语

做这个工具的初衷很简单:让普通人也能像专业交易者一样,快速获取和分析信息。

虽然遇到了 Exa 搜索不稳定、架构选择争议等问题,但这些挑战也让我更深入地思考了信息获取、AI推理、用户体验之间的平衡。
